Attribution rules

The initial safe defaults CostPilot applies across connected systems.

When a project ID is present Attribute the request automatically and record the model, cost, agent, source, and policy decision.
When no project is found Allow the request as unattributed work. The spend remains visible here so it can be corrected.
When a project is on hold Block new attributed requests without deleting the project or its audit history.
When a project reaches 80% of budget Surface it under Projects Needing Attention for review before the budget is exhausted.
