Complexity Keywords

Keywords use whole-term matching. For example, “NDA” does not match “Monday.” CostPilot provides starter recommendations, and administrators can remove any keyword.

Sensitive term library

Enable, disable, change, or delete the words and phrases used by your organization.

Text rules and automatic detectors are separate. Disabling a term such as “SSN” stops that phrase from triggering this library. Actual values such as formatted Social Security numbers, credit-card numbers, and API keys can still be identified by CostPilot’s automatic PII and secret-pattern detectors.
